## damilola-elegbede-org

The engineering home of [Damilola Elegbede](https://github.com/damilola-elegbede) — agent infrastructure,
client sites, and the tooling that runs them. Most repos are private; the main public ones are listed below.

### Public

| Repo | What it is |
|------|-----------|
| [claude-config](https://github.com/damilola-elegbede-org/claude-config) | Claude Code skills, hooks, and decision gates, deployed across an agent fleet |
| [codex-config](https://github.com/damilola-elegbede-org/codex-config) | Versioned Codex configuration — skills, subagents, and settings, mirrored from claude-config |
| [vscode-config](https://github.com/damilola-elegbede-org/vscode-config) | Portable VS Code setup — apply to any Mac, capture changes back, driven by a Claude skill |
| [pipedream-automation](https://github.com/damilola-elegbede-org/pipedream-automation) | Pipedream workflows syncing Gmail, Notion, and Google Tasks |
| [damilola-elegbede-org.github.io](https://github.com/damilola-elegbede-org/damilola-elegbede-org.github.io) | Architecture write-ups for the private projects below |
